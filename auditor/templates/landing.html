Nothing on the CV was different.

The only difference was the name.

Today, AI often reads your CV before any human does. And unlike our demo, the tools that read real CVs every day don't come with a warning label.

So how would anyone know?

We test it from the outside,
the way a recruiter would.

  1. 1

    One CV, eight names

    The same CV, rewritten under eight names: men and women, from two name groups. Only the name, email and he/she change.

  2. 2

    A placebo check

    Each CV also gets a second name from the same group. If even that changes the result, the tool reacts to names in general.

  3. 3

    Kane CLI applies

    Kane CLI from TestMu AI opens the real website, submits every CV and reads back each score. No access to the model, data or code.

  4. 4

    A verdict, with evidence

    PASS, BIASED or NAME-UNSTABLE, every number checked against Kane's own log, and a release that fails is blocked.
